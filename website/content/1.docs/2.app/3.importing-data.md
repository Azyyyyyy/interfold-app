# Importing data (app)

Interfold provides a way to import your existing data from PluralKit, Simply Plural, or a previously
exported Interfold backup. This allows you to easily transition to Interfold or move between Interfold
servers without having to manually re-enter all your alters.

Which import and export options appear in Settings depends on what your Interfold server supports.

**Note**: If you have any issues with the import process, please open an issue on
[GitHub](https://github.com/Azyyyyyy/Interfold-app/issues).

## Importing from Simply Plural

To import your alters from Simply Plural, you will need a Simply Plural access token. You can obtain a token by following
these steps:

- Open the Simply Plural app
- Open the side menu drawer and click the settings gear in the top right
- Navigate to the `Account` -> `Tokens` section
- Click the `+ Add Token` button, check the `Read` permission, and click the new `+ Add Token` button at the bottom of
  the screen
- Tap "Yes" three times to confirm the token creation, then hold tap on the new token to copy it to your clipboard.

Once you have the token, open the Interfold app and navigate to the Settings page. Scroll down to "Import alters" and tap
the "Import" button next to "Simply Plural." Then, paste the token you copied into the popup dialog and run the import!

The app will then import all your members, groups, front history, and custom fields from Simply Plural into Interfold. It
may take a few minutes for all of your data to be imported, especially if you have a large number of alters in Simply Plural.

## Importing from PluralKit

To import your alters from PluralKit, you will need your PluralKit access token. You can obtain this token by DMing
the PluralKit bot with the `pk;token` command.

Once you have the token, open the Interfold app and navigate to the Settings page. Scroll down to "Import alters" and tap
the "Import" button next to "PluralKit." Then, paste the token you copied into the popup dialog and run the import!

The app will then import all your members and groups from PluralKit into Interfold. It may take a few minutes for all
of your data to be imported, especially if you have a large number of alters in PluralKit.

## Importing an Interfold backup

If you previously exported an Interfold (or Octocon) backup JSON from Settings → Export data, you can import it again
from Settings → Import alters → Interfold backup. Choose the `.json` file when prompted.

The import runs in the background and typically restores user settings, alters, fronts, tags, and polls. Large backups
may take a few minutes. Avatars may continue importing after the main import finishes.

## Exporting data

From Settings → Export data you can download:

- **Interfold backup** — a full account backup (`interfold_export_octocon.json`) suitable for importing back into Interfold
- **PluralKit file** — a PluralKit-compatible export (`interfold_export_pk.json`) for use with PluralKit or other tools

Export options only appear when your server advertises them.
